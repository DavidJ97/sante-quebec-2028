# 0004 — Alignement sur HL7 FHIR et les terminologies canadiennes

**Statut :** acceptée · octobre 2026

## Contexte
Le schéma actuel a été conçu pour le prototype. Pour échanger avec les établissements, les pharmacies et le Dossier santé Québec, il faut parler la langue de l'industrie : HL7 FHIR R4, avec les profils canadiens.

## Correspondance

| Table | Ressource FHIR | Terminologie à ajouter |
|---|---|---|
| `personne`, `numero_qc` | Patient (identifiant QC, NAM en identifiant secondaire) | — |
| `filiation` | RelatedPerson, Patient.link | — |
| `procuration` | Consent | — |
| `lien_soins` | CareTeam ou EpisodeOfCare | — |
| `employe` | Practitioner, PractitionerRole | — |
| `allergie` | AllergyIntolerance | SNOMED CT, édition canadienne |
| `constat_absence` | AllergyIntolerance avec le code « No known allergy » | SNOMED CT |
| `medicament` | MedicationStatement | DIN de Santé Canada |
| `vaccin` | Immunization | Catalogue canadien des vaccins (CVC) |
| `maladie` | Condition, Device | SNOMED CT, CIM-10-CA |
| `volonte` | Consent, document de directives anticipées | — |
| `rendez_vous` | Appointment | — |
| `journal_acces` | AuditEvent (Basic Audit Log Patterns) | — |

## Décision
- Le schéma interne reste en français et optimisé pour les règles d'accès.
- L'échange se fait en FHIR, par une couche de traduction testée ressource par ressource.
- Les codes normalisés deviennent obligatoires à la saisie clinique. Le texte libre reste en complément.
